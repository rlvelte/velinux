# quickshell-config

A [Quickshell](https://quickshell.outfoxxed.me/) configuration featuring a Wayland bar, command center overlay, lock screen, and menus.

## Structure

| Path | Description |
|------|-------------|
| `shell.qml` | Root entry — assembles bar, command center, lock screen, and menus |
| `bar/` | Top panel with workspaces, hardware monitors (CPU/RAM/disk), clock, audio, tray, title, and command center launcher |
| `commandcenter/` | Overlay panel with system info header, RSS feeds, and Bundesliga table |
| `lock/` | Session lock screen with clock and PAM password authentication |
| `menus/` | Application picker (`vlx open`) and power menu (lock/logout/shutdown/reboot/BIOS) |
| `services/` | Theme palette (generated by `vlx-themes`) and Vlx singleton |

## Dependencies

- [Quickshell](https://quickshell.outfoxxed.me/) with Wayland
- A Wayland compositor (Hyprland or I3 for workspace support)
- PipeWire (for audio widget)
- SystemTray (for tray widget)
- PAM (for lock screen)
- [vlx](https://github.com/anomalyco/velinux) CLI — provides data for command center (feeds, Bundesliga, system info)

## Notes

- This config was built on **openSUSE Tumbleweed**. Some features (notably `vlx`-backed commands) may not work on other distros without adapting the command calls.
- The theme is generated by `vlx-themes` — replace `services/Theme.qml` with your own palette if not using that tool.
- The lock screen uses a PAM config at `lock/pam/password.conf`.
